가장 단순한 LiveKit 룸

GilJob v2는 아직 Zoom/Google Meet 같은 완성 화상회의가 아닙니다. 이 화면은 브라우저가 API에서 세션을 만들고, 반환된 LiveKit URL/token으로 로컬 self-hosted room에 join/leave 되는지 확인하는 제품형 스모크 UI입니다.

세션 생성 및 LiveKit 접속

idle

01

브라우저가 직접 방에 들어갑니다

LiveKit은 프론트와 백엔드 사이의 HTTP 프록시가 아니라, 브라우저와 media server가 만나는 room입니다.

02

URL 경계가 분리되어 있습니다

LIVEKIT_INTERNAL_URL은 컨테이너용, LIVEKIT_PUBLIC_URL은 브라우저용으로 유지합니다.

03

원시 토큰은 화면에 숨깁니다

candidate/session/report token은 브라우저 동작에만 쓰고, visible UI와 로그에는 redaction boundary를 둡니다.
