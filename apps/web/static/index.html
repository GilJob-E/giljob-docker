기능

GilJob-E 에서는

01

비언어 신호까지 읽는 멀티모달 평가

표정(영상), 음성 톤(오디오), 답변 내용(텍스트)을 함께 분석합니다. 단순한 답변 정확도를 넘어, 사람이 놓치기 쉬운 비언어 신호로 평가 근거를 만듭니다.

02

AI 면접관과 실시간 화상 면접

AI가 직무 맥락에 맞춰 질문을 생성하고, 음성과 아바타로 실제 사람과 대화하듯 면접을 이끌어 갑니다. 지원자는 언제 어디서든 동일한 조건으로 면접을 봅니다.

03

모든 지원자에게 같은 면접

면접관의 컨디션이나 주관에 따라 평가가 흔들리지 않습니다. 모든 지원자가 같은 질문 흐름과 같은 분석 기준으로 면접을 보기 때문에, 결과를 동일한 기준에서 비교할 수 있습니다.

평가 방식

신호를 성향으로

한 번의 면접에서 세 가지 모달리티를 모아 지원자의 성향 프로필을 산출합니다.

  1. 표정·시선 신호영상 분석
  2. 음성 운율·톤오디오 분석
  3. 답변 의미STT 텍스트 분석
  4. 성향 프로필정직·정서성·원만성·성실성

면접 흐름

준비부터 리포트까지

처음 면접 보는 지원자도 전체 흐름을 한눈에 확인 해 보세요.

  1. 면접 준비직무·지원 정보 입력
  2. 입장 전 점검카메라·마이크 확인
  3. 면접 진행질문에 답변
  4. 결과 리포트면접 후 평가 확인
