방으로 이동
01

Landing과 Room을 분리합니다

메인 페이지는 설명과 진입 CTA만 담당하고, 실시간 media UI는 `/interview-room.html`에서만 실행합니다.

02

LiveKit은 로컬 self-hosted입니다

LiveKit Cloud가 아니라 `kiostation`의 로컬 compose stack과 브라우저 direct media port를 사용합니다.

03

원시 토큰은 노출하지 않습니다

room page에서도 candidate/session/report token은 화면과 로그에 직접 렌더링하지 않습니다.
